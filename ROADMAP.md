# NovaOS Roadmap

## Phase 1: Foundation (v0.1 - Current)
- [x] Basic AOSP build environment and device tree setup.
- [x] Core Nova branding and UI overlays.
- [x] On-device AI service (NovaAIService) with basic NLP.
- [x] Minimalist Launcher (NovaLauncher) with AI integration.
- [x] Unified Settings (NovaSettings) with Privacy and Intelligence toggles.

## Phase 2: Privacy & Security (v0.2 - Upcoming)
- [ ] Fully functional NovaPrivacyCenter with per-app network control.
- [ ] Integration of NovaGuard for system-wide integrity monitoring.
- [ ] Enhanced App Lock and Privacy Vault features.
- [ ] Status bar indicators for Mic/Camera/Location usage.

## Phase 3: Intelligent Refinement (v0.3)
- [ ] On-device Small Language Model (SLM) for more complex queries.
- [ ] NovaDeviceCare with deep sleep management and storage optimization.
- [ ] Adaptive UI themes based on user habits and environment.
- [ ] Expanded system-wide AI text utilities.

## Phase 4: Public Beta (v0.5)
- [ ] Stable OTA update mechanism.
- [ ] Support for multiple reference devices (Pixel, OnePlus).
- [ ] Community feedback loop and bug reporting app.
- [ ] Documentation for third-party developers.

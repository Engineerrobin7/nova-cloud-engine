# NovaOS Changelog

## [v0.1-alpha] - 2024-06-09
### Added
*   **Foundation**: Core AOSP build system for `nova_emu_x86_64`.
*   **NovaAI**: Initial implementation of on-device AI service for NLP and translation.
*   **NovaLauncher**: Minimalist launcher with integrated "Nova Line" search bar.
*   **NovaSettings**: Unified settings app with dedicated Privacy and Intelligence sections.
*   **NovaPrivacyCenter**: Central hub for permission management and network shielding.
*   **NovaDeviceCare**: Performance and battery management utility.
*   **Essential Apps**: Nova-flavored Dialer, Browser, File Manager, and Gallery.
*   **Branding**: Custom "Celestial Blue" theme and visual identity.
*   **Documentation**: Core principles, architecture, roadmap, and business strategy.

### Fixed
*   Removed AOSP default bloatware from product packages.
*   Optimized build script for mid-range development environments.

### Security
*   Enabled AES-256-XTS encryption by default.
*   Restricted background network access for third-party apps.
